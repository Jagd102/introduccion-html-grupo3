Imagenes y enlaces en HTML

Para incluir imágenes y enlaces en HTML se usa <img src="URL_de_la_imagen" alt="texto alternativo"> para mostrar imágenes y <a href="URL_del_enlace">texto o imagen enlazada</a> para crear enlaces.

Para agregar una imagen en HTML:
La etiqueta <img> es un elemento vacío, lo que significa que no necesita una etiqueta de cierre. 
El atributo src especifica la URL o la ruta del archivo de la imagen. 
El atributo alt es esencial porque proporciona un texto alternativo si la imagen no se carga y ayuda a la accesibilidad. 
<img src="ruta/a/tu/imagen.jpg" alt="Descripción de la imagen">

Para agregar un enlace en HTML:
Usa la etiqueta <a> (ancla) con el atributo href. 
El valor de href es la URL a la que deseas dirigir al usuario. 
El texto o el contenido entre la etiqueta de apertura <a> y la de cierre </a> es lo que el usuario verá o podrá hacer clic. 
<a href="https://www.ejemplo.com">Visita ejemplo.com</a>
